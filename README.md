# Arthur Afonso — Portfólio

Portfólio pessoal desenvolvido em React e TypeScript. A página apresenta perfil,
stacks, projetos selecionados, princípios de trabalho, curiosidades e uma estante
de livros com avaliações.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
